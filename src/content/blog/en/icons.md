The theme has multiple icons available for use, covering social platforms (Bluesky, X/Twitter, LinkedIn, GitHub, Instagram, YouTube, Mastodon...) as well as common UI actions like `download`, `email`, `circle-info`, and directional arrows.

You can use them in several ways:

1. Inline in content, via a shortcode-style helper — see the [shortcodes documentation](/blog/) for details.
2. In the theme menus (header and footer), by referencing the icon name against a menu entry.
3. Directly as HTML/component markup, the same way `PlatformLinks` renders them in this port.

Do you need more icons? Check the project's issue tracker to see how to add your own, or request one if it's relevant to the wider community.
